# Send Email from Linux with Gmail or GMX

A lightweight command-line script for sending emails from Linux. Use it in your own scripts to deliver reports, alerts, and other automated messages.

## Features

- Send email from the Linux command line
- Use a Gmail or GMX account
- Integrate with scripts that generate reports or notifications
- Supports Debian, Ubuntu, Linux Mint, Kali Linux, Fedora, Red Hat, and other Linux distributions
- Supports Windows Subsystem for Linux (WSL)
